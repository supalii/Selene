# --- Peluncuran Pertama / Tanpa Core ---
Selene Core isn't running = Selene Core tidak berjalan
Selene is this theme plus its add-on, Selene Core. Install SeleneCore.pext from github.com/mattxslv/Selene/releases (open the file, or drag it onto Playnite's window), then restart Playnite. If it is installed already, make sure it is enabled under Add-ons. = Selene adalah tema ini beserta add-on miliknya, Selene Core. Pasang SeleneCore.pext dari github.com/mattxslv/Selene/releases (buka berkasnya, atau seret ke jendela Playnite), lalu mulai ulang Playnite. Jika sudah terpasang, pastikan add-on tersebut aktif di bawah menu Add-on.
Playnite's menu still opens from here (the Start / Menu button on a controller) to pick another theme meanwhile. = Menu Playnite tetap dapat dibuka dari sini (tombol Start / Menu pada pengontrol) untuk memilih tema lain sementara waktu.
